# Discord Tournament Bot – Kommandolista

En kompakt översikt över alla kommandon för botten, sorterat per roll.

## Admin-kommandon

- /setup
- /set-lobby [voice_channel]
- /tournament-create
- /tournament-start [tournament_id]
- /tournament-list [status]
- /tournament-cancel [tournament_id]
- /tournament-delete [tournament_id]
- /setup-match [match_id]
- /cleanup-match [match_id]
- /cleanup-all
- /resolve-dispute [match_id] [winner_id] [score_p1] [score_p2]

## Spelare-kommandon

- /signup [tournament_id]
- /withdraw [tournament_id]
- /my-tournaments
- /my-matches
- /my-stats
- /profile [@user]
- /leaderboard [category]
- /match-history [@user]

## Lag-kommandon

- /team-create [name] [tag]
- /team-invite [@user]
- /team-leave
- /team-info
- /team-list

## Turnering & Match-kommandon

- /report-win [match_id] [your_score] [opponent_score]
- /achievements
- /achievements-list

---

**Tips:**

- Parametrar inom [ ] är valfria eller kräver input.
